# Starbie

## Overview

Starbie is a custom electronics project built around the Seeed XIAO ESP32-C3. It combines a custom PCB, an OLED display, motion sensing, and physical controls its a tamagochi that i make for hackclub.

## What I Made

- Designed the Starbie PCB in KiCad.
- Integrated the XIAO ESP32-C3 microcontroller.
- Added an SSD1306 OLED display.
- Included an MPU6050 motion sensor.
- Added physical controls using switches compatible with the PCB footprints.
- Developed firmware for the device
